PORTABILIDAD

Datos y respaldo

GitHub Pages no escribe archivos en el repositorio. Por eso el contenido se conserva en este navegador y puede exportarse.

Exportar respaldo completo

Incluye cartas, decks, ajustes, imágenes, video de fondo y audio. Los archivos grandes producen un JSON grande.

Importar respaldo

Restaura una copia creada por esta misma versión. Los datos actuales serán reemplazados.

Restauración

Vuelve a las 100 cartas y los tres decks iniciales. También puedes borrar toda la multimedia local.

Entrada de GitHub Pages

index.html es el documento principal y main.js es el punto de entrada de la aplicación. Todo usa rutas relativas.

./index.html → data.js → animation/* → characters/* → effects/* → combat/* → game-systems.js → emblem-system.js → main.js

Tres diseños adaptativos

La interfaz puede detectar automáticamente el dispositivo o forzar los modos Escritorio, Móvil vertical y Móvil horizontal. La selección manual se conserva entre sesiones.

auto → desktop | mobile-portrait | mobile-landscape
