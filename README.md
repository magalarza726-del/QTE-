# QTE Lab v10.1.1

Aplicación web estática compatible con GitHub Pages.

## Cambios de esta corrección

- Biblioteca musical formada únicamente por archivos de audio importados por el usuario.
- Eliminadas todas las pistas procedurales integradas.
- Selección aleatoria entre las pistas importadas, evitando repetición inmediata cuando sea posible.
- Corregido el botón **Guardar carta**.
- Conserva cartas, animaciones, secuencias, emblemas, estadísticas, imágenes y respaldos de versiones anteriores.

## Publicación

Sube el contenido interno de esta carpeta a la raíz de la rama publicada. `index.html` debe quedar en la raíz.
