# Pruebas QTE Lab v8.2

Se comprobó el arranque del proyecto, la navegación y la ausencia de desbordamiento horizontal en:

- Escritorio: 1440 × 900.
- Móvil vertical: 390 × 844.
- Móvil horizontal: 844 × 390.

Pantallas verificadas en cada modo:

- Inicio
- Cartas
- Decks
- Batalla
- Multimedia
- Datos

También se comprobó:

- Cambio manual entre Automático, Escritorio, Móvil vertical y Móvil horizontal.
- Regreso correcto al modo automático.
- Editor de cartas a pantalla completa en móvil vertical.
- `index.html` y `main.js` como entrada compatible con GitHub Pages.
- Sintaxis válida de `main.js`.
